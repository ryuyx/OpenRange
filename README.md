# OpenRange

A GTO preflop opening range reference for Texas Hold'em. Displays standard 6-max 100BB RFI ranges by position.

Range data is based on GTO Wizard NL500 solutions.

## Features

- 13×13 hand grid with color coding for pairs / suited / offsuit hands
- GTO opening ranges for 5 positions (LJ / HJ / CO / BTN / SB)
- Real-time combo count and range percentage
- Hover tooltip showing combinations per hand

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · shadcn/ui

## Dev

```bash
npm install
npm run dev
```

## Build
